# Карта участков (прототип)

## Патч сессии

Правки нескольких объектов накапливаются в одной сессии вкладки. «Применить», смена объекта, закрытие формы и скачивание включают текущую правку в общий пакет. Последняя правка одного кадастра заменяет предыдущую. Кнопка «Скачать патч сессии (N)» выгружает все изменённые объекты одним JSON-файлом формата `{version:2, createdAt, patches:[...]}`; скачивание не очищает пакет.

Пакет хранится в sessionStorage этой вкладки и восстанавливается после её перезагрузки. Это локальные правки, а не запись в серверный реестр. Чтобы обновить сайт для всех, файл нужно применить скриптом `karta/apply_map_patch.ps1` к `allobjs.json`, пересобрать карту и опубликовать. Импортёр поддерживает одиночные старые патчи, массив и новый пакет, проверяет весь набор перед записью и создаёт резервную копию. В новом формате пустые переданные поля очищаются намеренно; отсутствующие поля сохраняются.

## Компактный интерфейс

На телефоне и сенсорном планшете подложка выбирается кнопкой «Карта»: меню содержит схему, спутник, гибрид, OpenStreetMap и отдельный переключатель кадастровой сетки. После выбора подложки меню закрывается. На телефоне оно открывается снизу, на планшете — у кнопки.

Карточка объекта на телефоне открывается снизу, на планшете — сбоку. В кратком виде показаны цена, площадь земли, цена за сотку, кадастр и ссылка Топнлаба. «Подробнее» раскрывает адрес, использование, категорию и кадастровую стоимость. Иконка возле кадастра копирует только номер. Обычный компьютер сохраняет всплывающую карточку с этой же кнопкой копирования.

В обычном сенсорном режиме показана одна кнопка выбора; «Рамка» и «Готово» появляются после включения выбора.

## Подборка и сравнение

На телефоне карта занимает экран, а список и фильтры открываются панелью снизу. На сенсорных устройствах кнопка «Выбрать» включает выбор нажатиями, «Рамка» — выделение областью одним пальцем, «Готово» возвращает обычное управление. Во время рамки область внутри остаётся светлой, карта снаружи затемняется. Два пальца отменяют незавершённую рамку и позволяют масштабировать карту. На планшете в широком окне сохраняется боковой список.

- В «Площадь, цена за сотку и сортировка» задаются диапазоны площади земли в сотках и цены за сотку, а также порядок списка. Границы диапазонов включаются.
- Цена за сотку считается из отображаемой цены только для участков. У домов, квартир, объектов с неизвестным типом или недостаточными данными — «—». Незаполненные значения при сортировке идут в конец.
- Shift + клик по объекту или строке переключает выбор. Shift + перетаскивание добавляет объекты в рамке по их центральным маркерам, не перемещая карту. Обычное перетаскивание перемещает карту. Можно выбирать и флажками в списке, в том числе на сенсорном экране.
- «Только выбранные» ограничивает карту подборкой совместно с фильтрами. Счётчик сообщает о скрытых фильтрами выбранных объектах. Выбор сохраняется при фильтрации и изменении масштаба, до перезагрузки страницы.
- «Сравнить» открывает таблицу всех выбранных объектов (от двух). Из таблицы можно убрать объект или перейти к нему, сбросив скрывающие его фильтры. Ссылка Топнлаба доступна и в клиентском режиме.
- «Копировать» сохраняет в буфер все выбранные кадастровые номера, каждый с новой строки, без цен и заголовков. Включает скрытые фильтрами выбранные объекты; порядок соответствует сортировке списка. Кнопка доступна в списке, сравнении и сенсорной панели.
- «Снять выделение» очищает подборку. Escape отменяет рамку, закрывает сравнение либо снимает выделение вне полей ввода.

Проверка расчётов, фильтров, выбора и обработчиков рамки без зависимостей: `node tests/selection.test.cjs`.
Проверка копирования: `node tests/clipboard.test.cjs`.

## Территории и масштаб

Объекты видны на любом масштабе, без групповых карточек. До масштаба 12 цвет общий для муниципальной территории (Алушта — тёмно-зелёная), с 12 — свой для каждого населённого пункта. «Все территории» возвращает обзор. Фильтры муниципальной территории и населённого пункта работают совместно. Официальные административные границы не нанесены.

Справочник населённых пунктов: `../karta/settlements.csv`. Журнал разработки и оставшиеся задачи: [CHANGELOG.md](CHANGELOG.md).

Статический сайт для Vercel. Вход по логину и паролю (`middleware.js`).

## Файлы
- `index.html` — сама карта.
- `data/objects.js` — наши участки. Обновляется без пересборки сетки.
- `data/grid/*.js` — кадастровая сетка кусками; грузится только то, что видно на экране при сильном приближении.
- `middleware.js` — проверка логина и пароля.

## Логины
Vercel → проект → Settings → Environment Variables → `MAP_USERS`:
```
vadim:придумайте-пароль,zakazchik:другой-пароль
```
Убрать человека: удалить его пару и нажать Redeploy.

## Обновление данных
На компьютере: `KadastrKim\karta\build.ps1 ... -Site KadastrKim\site` пересобирает `index.html` и `data/objects.js`.
Сетка — `KadastrKim\karta\build_grid_chunks.ps1 -Site KadastrKim\site`, только когда она меняется.
Затем отправить изменения на GitHub — Vercel обновит сайт сам.
